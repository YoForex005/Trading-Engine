PROBLEM
================================================================================
MarketWatch component displayed "---" for all prices despite backend
successfully broadcasting market data via WebSocket.

ROOT CAUSE:
- WebSocket handler only updated useAppStore
- MarketWatch component reads from useMarketDataStore
- Missing data bridge between stores caused broken data flow

================================================================================
SOLUTION
================================================================================
Modified: clients/desktop/src/App.tsx (line 413)

Added call to useMarketDataStore.getState().updateTick() in WebSocket
onmessage handler to ensure both stores receive tick data.

BEFORE:
  ws.onmessage → useAppStore.setTick() → Chart (works)
                                       → MarketWatch (broken)

AFTER:
  ws.onmessage → useAppStore.setTick() → Chart (works)
               → useMarketDataStore.updateTick() → MarketWatch (FIXED)
