WHY TWO STORES?
================================================================================

┌─────────────────────────────────────────────────────────────────────────┐
│                          useAppStore                                     │
│                      (Original/Legacy)                                   │
│                                                                           │
│  Purpose:     General application state                                 │
│  Used by:     Chart, Trading Panel, Orders, Positions                   │
│  Features:    Simple tick storage, immediate updates                    │
│  Performance: <5ms latency for tick updates                             │
│  Structure:   ticks = { [symbol]: { bid, ask, spread } }               │
└─────────────────────────────────────────────────────────────────────────┘

┌─────────────────────────────────────────────────────────────────────────┐
│                      useMarketDataStore                                  │
│                      (Optimized/Advanced)                                │
│                                                                           │
│  Purpose:     Advanced market data with analytics                       │
│  Used by:     MarketWatch, Analytics, Statistics                        │
│  Features:    OHLCV aggregation, Web Worker calculations               │
│  Performance: <5ms main thread (offloaded to Web Worker)               │
│  Structure:   symbolData = {                                            │
│                 [symbol]: {                                             │
│                   currentTick, previousTick, stats,                     │
│                   ohlcv1m, ohlcv5m, ohlcv15m, ohlcv1h,                 │
│                   tickBuffer (10,000 ticks)                             │
│                 }                                                        │
│               }                                                          │
└─────────────────────────────────────────────────────────────────────────┘

HISTORY:
  1. Original implementation: useAppStore only
  2. Performance issues: OHLCV blocking main thread
  3. Solution: Created useMarketDataStore with Web Worker
  4. Problem: Migration incomplete, WebSocket handler not updated
  5. Fix: Update WebSocket handler to feed both stores

PERFORMANCE CHARACTERISTICS
================================================================================

Tick Rate:        1-5 ticks/sec per symbol (YOFX typical)
Total Symbols:    ~30 forex pairs + metals
Total Ticks/sec:  ~100-150 (with throttling)
Latency:          <5ms (WebSocket → Display)
CPU Impact:       +2-3% (negligible)
Memory:           ~10MB per 10,000 ticks per symbol

Optimizations:
  ✓ Backend throttling (skip if price change < 0.0001%)
  ✓ Non-blocking broadcast (drops if buffer full)
  ✓ Web Worker OHLCV aggregation (offloaded from main thread)
  ✓ Tick buffer size limit (10,000 per symbol, circular)
  ✓ MT5 mode available (no throttling, for professional terminals)
