CRITICAL ERROR INDICATORS
========================
Backend:
  - "panic:"              = CRASH (CRITICAL)
  - "ERROR"               = Error condition
  - "FATAL"               = Fatal error, will exit
  - "failed to"           = Operation failed
  - "address already in use" = Port conflict

Frontend:
  - "[vite] Internal Server Error" = Build failed
  - "error TS"            = TypeScript error
  - "CORS error"          = Can't reach backend
  - "Cannot find module"  = Missing dependency

COMMON ISSUES & FIXES
====================

Issue: Backend won't start
  Fix 1: Check port: netstat -ano | findstr :8080
  Fix 2: Kill other process: taskkill /PID [PID] /F
  Fix 3: Check logs: tail -50 backend.log

Issue: "address already in use"
  Fix: netstat -ano | findstr :8080 && taskkill /PID [PID] /F

Issue: Frontend CORS errors
  Fix 1: Verify backend running: curl http://localhost:8080/health
  Fix 2: Check API config: clients/desktop/src/config/api.ts
  Fix 3: Verify backend CORS headers

Issue: npm build fails
  Fix 1: npm install && npm install
  Fix 2: rm -Force node_modules && npm install
  Fix 3: rm -Force .vite && npm run dev

Issue: "Cannot find module"
  Fix: npm install in the affected directory
