# Print Functionality - Quick User Guide

## How to Print Charts

### Method 1: Quick Print (Fastest)
1. Press **Ctrl+P** on your keyboard
2. Your chart will print using saved settings
3. Choose your printer in the browser dialog
4. Click Print

### Method 2: Print with Preview
1. Click **File** menu → **Print Preview**
2. Review your chart in the preview window
3. Use zoom controls (+/- buttons) to adjust view
4. Click **Print** button when ready
5. Complete the browser print dialog

### Method 3: Print with Custom Settings
1. Click **File** menu → **Print Setup**
2. Configure your preferences:
   - **Page Size**: Choose A4, Letter, Legal, or A3
   - **Orientation**: Select Portrait or Landscape
   - **Margins**: Adjust spacing (0-50mm)
   - **Options**: Toggle headers, footers, legends
   - **Color Mode**: Choose Color or Black & White
3. Click **OK** (Preview opens automatically)
4. Review and click **Print**

## Print Options Explained

### Page Settings
- **Orientation**
  - **Landscape** (recommended for charts): Wide format, fits more data
  - **Portrait**: Tall format, good for detailed analysis

- **Paper Size**
  - **A4**: Standard international size (210 × 297 mm)
  - **Letter**: Standard US size (8.5 × 11 in)
  - **Legal**: US legal size (8.5 × 14 in)
  - **A3**: Large format (297 × 420 mm)

### Content Options
- **Include Header**: Shows symbol, timeframe, and date range at top
- **Include Footer**: Shows page info and custom text at bottom
- **Include Grid Lines**: Prints chart grid for easier reading
- **Include Indicators Legend**: Lists all active technical indicators
- **Include Drawings Legend**: Lists all drawings and annotations
- **Scale to Fit Page**: Automatically sizes chart to fill page

### Customization
- **Header Text**: Add custom title (e.g., "Monthly Analysis Report")
- **Footer Text**: Add custom footer (e.g., "Confidential - Internal Use Only")
- **Color Mode**:
  - **Color**: Full color printing (recommended)
  - **Black & White**: Grayscale for draft or economy printing

## Tips for Best Results

### ✅ DO:
- Use **Landscape orientation** for most charts
- Enable **Scale to Fit Page** for optimal sizing
- Check **Print Preview** before printing expensive color pages
- Save your preferences if you print frequently
- Use **Color mode** for professional presentations
- Include **legends** when sharing with others

### ❌ DON'T:
- Don't print without previewing first (wastes paper)
- Don't use Portrait for wide time ranges (chart will be tiny)
- Don't disable headers/footers when archiving (need context)
- Don't use tiny margins (may cause clipping)

## Troubleshooting

### Problem: Nothing Prints
**Solution**:
1. Make sure a chart is visible on screen
2. Try Print Preview first to see if chart is captured
3. Check browser console (F12) for errors

### Problem: Chart is Blank on Print
**Solution**:
1. Wait for chart to fully load before printing
2. Try zooming in/out on the chart first
3. Use Print Preview to verify capture

### Problem: Colors Don't Print
**Solution**:
1. Check Print Setup → Color Mode is set to "Color"
2. Verify your printer supports color
3. Check printer settings (not set to grayscale)

### Problem: Chart is Too Small/Big
**Solution**:
1. Enable "Scale to Fit Page" in Print Setup
2. Try different orientation (Landscape vs Portrait)
3. Use Print Preview zoom to check before printing

### Problem: Preferences Don't Save
**Solution**:
1. Make sure "Save as default" checkbox is checked
2. Check if you're logged in
3. Try again after page refresh

### Export to PDF
Instead of printing to paper:
1. Open Print Preview
2. Click Print
3. In browser dialog, select "Save as PDF" or "Microsoft Print to PDF"
4. Choose save location

## Best Practices

1. **Always Preview First**: Saves paper and toner
2. **Use Landscape**: Better for time-series charts
3. **Include Context**: Enable headers with date ranges
4. **Save Preferences**: Set once, use many times
5. **Check Before Sharing**: Ensure legends are included
6. **Use PDF for Digital**: Smaller file size than images
