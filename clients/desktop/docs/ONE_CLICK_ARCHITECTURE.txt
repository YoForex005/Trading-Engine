┌─────────────────────────────────────────────────────────────────────────────┐
│                       DATA FLOW SEQUENCE                                    │
└─────────────────────────────────────────────────────────────────────────────┘

1. User Action
   └─→ User presses Ctrl+Shift+T or right-clicks chart

2. Panel Activation
   └─→ TradingChart sets oneClickTrading = true
   └─→ OneClickPanel renders

3. First Time Use
   └─→ Check localStorage for 'oneClickTradingAccepted'
   └─→ If not found, show disclaimer modal
   └─→ User clicks "I Understand, Enable"
   └─→ Store acceptance in localStorage

4. Volume Adjustment (Optional)
   └─→ User clicks +/- buttons or types value
   └─→ Volume state updates (min 0.01, rounded to 2 decimals)

5. Default SL/TP Loading
   └─→ Check localStorage.getItem('defaultStopLoss')
   └─→ Check localStorage.getItem('defaultTakeProfit')
   └─→ Calculate actual prices based on pips

6. Order Placement
   └─→ User clicks BUY or SELL button
   └─→ placeOrder('BUY' | 'SELL') called
   └─→ Set isPlacing = true (disable buttons)
   └─→ Build order payload with SL/TP

7. API Call
   └─→ api.orders.placeMarketOrder(orderData)
   └─→ fetchWithTimeout adds JWT token
   └─→ POST to http://localhost:7999/api/orders/market

8. Backend Processing
   └─→ Validate JWT token
   └─→ Validate order data
   └─→ Check margin requirements
   └─→ Execute order (A/B/C-Book routing)
   └─→ Update database (positions, account, ledger)
   └─→ Return Position object

9. Success Response
   └─→ API returns position data
   └─→ OneClickPanel: isPlacing = false
   └─→ Call onOrderPlaced() callback
   └─→ TradingChart may refresh positions list
   └─→ WebSocket broadcasts position update to all clients

10. Error Handling
    └─→ API throws error
    └─→ Catch in try-catch block
    └─→ Set error state with message
    └─→ Display red error notification
    └─→ Auto-dismiss after 3 seconds
    └─→ isPlacing = false (re-enable buttons)

│                        KEYBOARD SHORTCUTS                                   │
└─────────────────────────────────────────────────────────────────────────────┘

    Ctrl+Shift+T
         │
         ├─→ useEffect in TradingChart.tsx
         │    └─→ addEventListener('keydown', handler)
         │         └─→ if (e.ctrlKey && e.shiftKey && e.key === 'T')
         │              └─→ e.preventDefault()
         │                   └─→ setOneClickTrading(prev => !prev)
         │
         └─→ Result: Panel toggles on/off

┌─────────────────────────────────────────────────────────────────────────────┐
│                         SAFETY MECHANISMS                                   │
└─────────────────────────────────────────────────────────────────────────────┘

1. Disclaimer System
   ┌────────────────────────────────────────┐
   │ localStorage.getItem('oneClick...')    │
   │  ↓                                     │
   │ null? → Show warning modal             │
   │  ↓                                     │
   │ User accepts → setItem('...', 'true')  │
   │  ↓                                     │
   │ Never show again                       │
   └────────────────────────────────────────┘

2. Volume Validation
   ┌────────────────────────────────────────┐
   │ Input: volume                          │
   │  ↓                                     │
   │ Check: volume > 0                      │
   │  ↓                                     │
   │ Round: Math.round(vol * 100) / 100     │
   │  ↓                                     │
   │ Min: Math.max(0.01, volume)            │
   └────────────────────────────────────────┘

3. Duplicate Prevention
   ┌────────────────────────────────────────┐
   │ isPlacing = true                       │
   │  ↓                                     │
   │ Buttons disabled                       │
   │  ↓                                     │
   │ API call executes                      │
   │  ↓                                     │
   │ isPlacing = false                      │
   │  ↓                                     │
   │ Buttons re-enabled                     │
   └────────────────────────────────────────┘

4. Error Recovery
   ┌────────────────────────────────────────┐
   │ try { api.orders.place... }            │
   │  ↓                                     │
   │ catch (err) {                          │
   │   setError(err.message)                │
   │   setTimeout(clear, 3000)              │
   │   isPlacing = false                    │
   │ }                                      │
   └────────────────────────────────────────┘
