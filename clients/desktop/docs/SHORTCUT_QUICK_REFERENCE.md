## Tips

### Input Protection
- Most shortcuts are disabled when typing in text fields
- F-keys and Escape always work
- Use Escape to exit input fields

### Visual Feedback
- All shortcuts show a visual confirmation toast
- Symbol name shown for trading actions

### Customization
- Press F1 to see all available shortcuts
- Search for specific shortcuts
- See which shortcuts are enabled/disabled

### Conflicts
- System automatically resolves conflicts by priority
- Warnings shown in F1 help dialog
- Check browser console for details

## Platform Notes

### Windows/Linux
- Use `Ctrl` key for shortcuts

### macOS
- Use `Cmd` (⌘) key instead of `Ctrl`
- `Alt` = `Option` (⌥)

## Common Issues

### Shortcut Not Working?
1. Check if typing in an input field
2. Press F1 to verify shortcut is registered
3. Check browser console for errors

### Wrong Action Triggered?
- Conflict detected - check F1 help for warnings
- Close any open modals/dialogs
- Ensure correct window is focused
